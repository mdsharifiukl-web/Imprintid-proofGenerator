    Bulk Import from Spreadsheet

    Import many item codes/colors at once from a CSV or Excel file exported from your website or product spreadsheet. Each row is one color (and optionally one imprint method) of a product; rows sharing the same Item Code become one product. BackImageURL is optional — fill it in for products with a back-side print. Product Width/Height and Imprint Method/Width/Height columns are optional — fill them in to get automatic sizing on the order form.
    For photos, either put a public web address in the ImageURL/BackImageURL columns, or just put the plain file name (e.g. navy-front.jpg, no folder path) and upload the actual image files below — no hosting needed. Either order works: if you import the CSV before uploading the matching images, just upload them after and they'll fill in automatically.
